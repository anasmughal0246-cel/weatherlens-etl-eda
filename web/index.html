    Heatwave detector

    A heatwave is a run of consecutive days when the daily maximum stays at or above your limit.
    40 °C

    Longest heatwaves

    Top events, longest first.
    How it is computed: for each city we walk through the days in order and count how many days in a row have tmax >= limit. Runs shorter than the minimum are ignored. Uses the From and to years at the top.

    Dry spell tracker

    A dry spell is a run of consecutive days with less than 1 mm of rain, the same rule that defines a rainy day.

    Longest dry spell each year

    Number of days in a row without a rainy day.

    Longest dry spells

    Top events, longest first.
    How it is computed: the same walk through the days, counting days in a row with rain < 1 mm. Uses the From and to years at the top.

    Yearly temperature trend

    The average temperature of each year with a straight trend line fitted through it.
    Be careful: a few years is a short record. The slope is a hint about direction, not proof of climate change. One unusually hot or cool year can move it a lot.
    How it is computed: the average of tmean for each year, then a least-squares line. The slope is the change in °C per year. Uses the From and to years at the top.

    The pipeline, step by step

    Each step is its own Python file, so every part is easy to explain and test.
    1. Extract extract.pyCalls the Open-Meteo Archive API with the requests library for each city (latitude, longitude, dates) and gets JSON back.
    2. Transform transform.pyTurns the JSON into a pandas DataFrame, checks every row with Pydantic, and adds month and is_rainy (1 mm or more of rain).
    3. Load load.pySaves the clean table into a SQLite database, weather.db. Rejected rows would go to a separate table.
    4. Run everything pipeline.pyLoops over the three cities and runs extract, transform and load in order.
    5. Analyse eda.pyPrints shape, missing values, summary statistics and correlation, and saves four graphs.
    6. Publish export_data.pyWrites data.json from the database. This website reads that file and draws every chart in your browser.

    Validation rules (Pydantic)

    Open-Meteo Archive API (free, no API key). Daily values for Lahore, Karachi and Islamabad from 1 January 2020 to 31 December 2025. The values come from a weather reanalysis, so they show patterns well but are not a single weather station reading.
